# Hand Pen — Gesture Drawing

Hand Pen is a browser-based gesture drawing application that allows users to draw in the air using only their index finger and a webcam. Powered by real-time hand tracking, the application transforms finger movements into smooth digital strokes, creating a natural and intuitive drawing experience without the need for a graphics tablet or touchscreen.

Featuring a clean, minimalist interface with a dark theme and glowing golden brush effects, Hand Pen provides an immersive environment for creative expression. The application includes stroke smoothing, undo and redo functionality, responsive controls for both desktop and mobile devices, and accurate real-time hand tracking.

## Features

- ✨ Draw using natural hand gestures.
- 🖐️ Real-time hand and finger tracking.
- 🎨 Smooth glowing brush strokes.
- ↶ Undo and redo support.
- 📱 Compatible with desktop and mobile devices.
- 🌙 Modern, minimalist, and responsive interface.
- ⚡ Runs entirely in the browser with no installation required.

Hand Pen showcases how computer vision and artificial intelligence can be used to create an interactive digital drawing experience, turning simple hand movements into a creative and accessible virtual canvas.
